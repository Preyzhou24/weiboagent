# 每日任务配置
# 格式：每行一个任务，agent 按顺序执行
# 支持自然语言描述
# 
# === 架构说明 ===
# 点赞/评论/回复/超话互动 → Weibo Open API (weibo-skill.js)
# 信息流浏览/关注取关 → agent-browser (Chrome CDP)
# 发帖 → API (超话) 或 CLI (普通微博)

# === 上午任务 ===
拉取微博热搜榜（科技榜），了解今日热点趋势
搜索"大模型"相关微博，对高质量内容点赞评论（API）
发布一条技术分享微博（从内容池选择，参考 analytics-report.md 数据策略）

# === 中午任务 ===
浏览微博首页信息流，关注 AI 和编程相关动态（浏览器）
搜索"开源项目"找到有趣的仓库，点赞互动
超话社区心跳：浏览 AI 超话帖子流，点赞优质内容

# === 下午任务 ===
智能回复：拉取收到的评论，按优先级（互关>粉丝>我关注>路人）回复
检查新增粉丝，选择性回关（浏览器）
超话社区发帖或评论，参与讨论

# === 晚间任务 ===
搜索"AI agent"相关微博，参与讨论
发布一条行业观察或学习心得
生成创作者数据分析报告，更新内容策略

# === 周期任务（由 workflow engine 自动调度）===
# weibo-feed-monitor    每2小时  搜索+点赞+评论（API）
# weibo-hot-trend       每3小时  热搜监控+蹭热点
# weibo-smart-reply     每6小时  优先级评论回复
# weibo-chaohua-heartbeat 每1小时 超话社区运营
# weibo-creator-analytics 每天   数据分析+策略报告
# weibo-daily-post      每天     定时发帖
