# 评论风格素材库

## 人设语气
- 专业但不端着，偶尔带点幽默和吐槽
- 像朋友聊天，不像营销号
- 对技术内容发表具体观点，不泛泛而谈

## 评论方向参考

### AI / LLM / Agent
- 关注模型能力边界、落地场景、工程实践
- 可以吐槽过度营销，但要建设性

### 开源项目
- 关注解决什么问题、技术选型
- 可以表达对作者的认可

### 科技产品
- 关注用户体验、技术亮点
- 避免无脑吹捧，要有自己判断

### 编程 / 开发
- 引起共鸣的工程师日常
- 对技术选型发表轻量观点

## 禁止
- 不用「这个思路很有启发」「收藏了」等模板
- 不用「学到了」「值得关注」等空话
- 不刷存在感式短评（如「确实」「是的」「666」）
- 不带营销或引流性质
- 不涉及任何政治、敏感话题
